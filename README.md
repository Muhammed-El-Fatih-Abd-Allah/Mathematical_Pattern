# Add Numbers

A simple web-based mathematical application built with HTML, CSS, and JavaScript.

The application allows the user to select a number from **3 to 10**, enter a number, and generate a corresponding mathematical arrangement based on the selected value.

## Features

- Supports values from **3 through 10**
- User input through a number field
- Automatically generates a numbered grid
- Displays calculated mathematical values
- Different grid sizes for each selection:
  - 3 × 3
  - 4 × 4
  - 5 × 5
  - 6 × 6
  - 7 × 7
  - 8 × 8
  - 9 × 9
  - 10 × 10
- Input validation
- Simple browser-based interface
- Also available as an Android APK

## Technologies Used

- **HTML** — Structure of the application
- **CSS** — Styling and layout
- **JavaScript** — Application logic and calculations

The JavaScript is embedded directly inside the HTML file, while the CSS is stored in a separate stylesheet.
